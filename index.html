How Bitwarden protects data

Bitwarden ทำงานอย่างไร

ข้อมูลใน Vault ถูกเข้ารหัสที่อุปกรณ์ก่อนซิงก์ขึ้นเซิร์ฟเวอร์ และจะถอดรหัสเมื่อเจ้าของปลดล็อกผ่านแอป Bitwarden เท่านั้น ผู้ดูแล Passly จึงไม่ต้องนำ Master Password หรือรหัสจริงมาเก็บในเว็บนี้

  1. 1
    สร้างและเก็บใน Vaultบันทึก Login หรือ Secure Note ในบัญชีส่วนตัวหรือ Organization
  2. 2
    เข้ารหัสก่อนซิงก์ข้อมูลที่ส่งไป Bitwarden Cloud หรือเซิร์ฟเวอร์องค์กรอยู่ในรูปเข้ารหัส
  3. 3
    ปลดล็อกที่อุปกรณ์ผู้ใช้ถอดรหัสผ่าน Master Password, PIN หรือ Biometrics ตามนโยบาย

ช่องทางใช้งาน Bitwarden

Web Vaultตั้งค่าบัญชี, Organization, Collections, สิทธิ์สมาชิก และ Send
Browser Extensionบันทึก สร้าง และกรอก Username/Password บนเว็บไซต์ประจำวัน
Mobile Appเปิด Vault และ Autofill ในแอปหรือเบราว์เซอร์บนโทรศัพท์
Desktop Appจัดการ Vault บน Windows/macOS/Linux และใช้ Biometrics เมื่อรองรับ
CLIสำหรับทีม IT และงานอัตโนมัติ ไม่ใช้เป็นช่องทางแจก Password ให้พนักงานทั่วไป

ขั้นตอนแจก Password ที่แนะนำ

1อนุมัติคำขอตรวจผู้ขอ ระบบ และวัตถุประสงค์ใน Passly
2สร้าง Text Sendเปิด Bitwarden → Send → New → Text
3จำกัดการเข้าถึงซ่อนข้อความ ตั้งหมดอายุ ลบอัตโนมัติ และจำกัดจำนวนเปิด
4ส่งลิงก์และบันทึกวางลิงก์ Send ใน Passly แล้วบันทึกเฉพาะหลักฐานการส่ง

ทีม

แนะนำ

ไฟล์

Bitwarden Send — File

ส่งเอกสารหรือไฟล์เข้ารหัส เหมาะกับข้อมูลแนบ และต้องใช้ Premium หรือ Organization แบบชำระเงิน

ค่ามาตรฐานของ Fern Clinic

ใช้เป็น checklist ทุกครั้งก่อนคัดลอกลิงก์ Send

  • ✓ ใช้ Text Send และเปิด Hide text by default
  • ✓ Expiration 1 ชั่วโมง · Deletion 1 วัน
  • ✓ จำกัดการเปิด 1 ครั้ง เมื่อเป็นรหัสสำคัญ
  • ✓ ใช้ Password protection หรือ Email verification
  • ✓ ห้ามวาง Password จริงใน LINE, Lark, Sheets หรือ Passly
